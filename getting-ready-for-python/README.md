## Operating System Terms

| Term | Meaning |
|---|---|
| Operating system (OS) | The software that manages computer hardware and provides services that applications and users rely on. |
| Kernel | The core part of an operating system. It communicates with hardware and manages resources such as memory, processes, files, and devices. |
| User space | The part of the operating system where normal applications and user programs run, outside the kernel. |
| Linux | An open-source operating system family that people can use, modify, and distribute under its software licenses. |
| Windows | An operating system developed by Microsoft. |
| macOS | An operating system developed by Apple. |
